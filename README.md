# Tinkers Construct (Unofficial port)

**This is an unofficial port of Tinkers' Construct. It is not developed, approved, or supported by SlimeKnights.**

Tinkers Construct (Unofficial port) brings the Tinkers' Construct experience to **Minecraft 1.21.1 on NeoForge**.

## Features and New Features

- Modular tools, weapons, shields, **~~and armor~~ (only with coarm, still in development)**
- Smelting, alloying, casting, and molten metals
- Custom materials, traits, and modifiers
- Optional Create integration for ores, fluids, pipes, and tanks and others things under development
- Additional compatibility with Sable and Create Aeronautics

![Tinkers' X Create](https://cdn.modrinth.com/data/3xgZFdrY/images/b71e9b23012af037d092f87059324ef34bc11a2d.png)

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.x
- Java 21

Please report issues to this port only, not to the official Tinkers' Construct team.
